Careers

Roles from employers a person has checked.

Verification is a person’s judgement about who is behind a posting — a fake employer here is not a spammer, it is a CV-harvesting attack. Applications are made inside PCI World with recorded consent, and that consent stays the applicant’s to withdraw.

Careers

A job page

/world/careers/northwind/senior-planning-engineer

A crawlable job page. Structured data is a claim made to a search engine, so it is computed when the page is drawn rather than left behind by a job that has since closed.

Enforced by the real server

  • Carries JobPosting structured data only while it is open
  • Once closed: page stays readable, markup disappears, leaves the sitemap
  • No external apply link — ever

Careers

Employer portal

/world-app/ → Employer portal

The employer’s side. Note the second organisation: it can write postings all day and the publish control refuses, in words, with the reason.

Enforced by the real server

  • An unverified employer can draft everything and publish nothing
  • One employer can never see another’s applicants
  • Suspending an employer cuts its access mid-session, not at next login

Careers

My applications

/world-app/ → My job applications

The applicant’s own view. The design decision worth seeing: withdrawing consent does not delete the record that consent existed, because “was there consent the day they read this?” has to stay answerable afterwards.

Enforced by the real server

  • Withdrawing consent stops the employer immediately
  • The consent record survives withdrawal
  • Withdrawal is not erasure — and says so
