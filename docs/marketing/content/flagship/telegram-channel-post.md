**Fourteen CPI points went missing in an accrual, not a schedule.**

Earned value 2,200,000. Invoiced cost 1,850,000.

```
2,200,000 ÷ 1,850,000 = CPI 1.19
```

Then someone asks what is done and not yet invoiced: 240,000.

```
1,850,000 + 240,000 = 2,090,000
2,200,000 ÷ 2,090,000 = CPI 1.05
```

Same month, same project. Both numbers were reported honestly. Only one of them was true.

Nothing was overspent. Nothing slipped. Earned value had counted that 240,000; the ledger had not seen it.

The error is accounting. The damage is delivery. Neither training alone catches it.

You sign the forecast. Miss the accrual and the number you defended was wrong before you saw it.
