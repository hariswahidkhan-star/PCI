### The five rules that never change

1. One sentence of context, then the quotation. Nothing above it to scroll past.
2. The quotation is written to be pasted with no edits, in the first person, with no organisation name inside it. A writer strikes self-reference from a quote; write it so there is nothing to strike.
3. Every factual claim in the response is checkable in the one URL you give them, or it does not go in.
4. Plain text. No attachment, no logo, no shortener, no tracking, no CC.
5. No follow-up, ever. Not a nudge, not a "just checking you saw this".

### What is rewritten every time

- **The subject line.** Paste the query headline exactly. It is how the response reaches the right thread and, on some services, how it reaches the writer at all.
- **The first sentence.** Name the specific part of their question you can answer, in their own words, and name what you are not answering. This is the only sentence that must be rewritten for every query, and it is the one that decides whether the quotation is read.
- **The length of the quotation.** If the query asked for a comment rather than a block, send the first sentence and the last three. They stand alone, and they are the cut that keeps both professions named. Cutting to the last two drops "Accountancy examinations rarely test float" and leaves only the line about engineers, which turns a structural argument into a side. The offer line in the response says the same thing, so the writer cuts it the way it was built to be cut.
- **The URL.** The syllabus by default; the verification page instead, never as well, on a query about checking credentials.

### What never goes in, on any query

Accreditation, recognition, endorsement, affiliation or partnership. Pass rates, salary figures, student numbers, outcome claims. Any examination weighting: 40/40/20 describes the Body of Knowledge and never the examination, and the safest handling in a format this short is to leave it out entirely. Any number not in the approved register. A named client, sector or date attached to the arithmetic. A booking, a cohort, a sitting or a date, because the syllabus is settled and the examination blueprint is an open decision, and nothing in a response may imply there is a place to buy.

### When it is published

Do not ask for a link, and do not ask for a link to be changed. Thank them once, in two lines, and say the offer stands for the next piece. If the arithmetic has been printed as a real project despite the label, ask once and politely for the word "illustrative" to be added; that is the only correction worth making and it is worth making every time. Log the outlet and the writer so that no other asset in this run reaches the same person with a different angle in the same month. Cite the published article once from the Institute's newsroom. There is no "as featured in" wall, and building one is how a body that has just refused to publish a pass rate loses the credit for refusing.
