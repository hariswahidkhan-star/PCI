# Five days late, and the float column shows nothing

*X / Threads thread — 7 posts, each under 280 characters and each able to stand alone. The link sits in the first reply, not in the thread. X counts any URL as 23 characters.*

**Post 1/7 — the hook** (232 characters)
Three activities in sequence: 10 days, then 20, then 25.
The forward pass lands on day 55. The package reports zero total float on all three.
The contract date is day 50.
The programme is five days late and no float column shows it.

**Post 2/7 — why the tool is right** (232 characters)
With no project finish date entered, the backward pass starts from the calculated finish. Late dates equal early dates, so float is zero everywhere.
That is arithmetically correct. The contract date was simply never put in the file.

**Post 3/7 — the fix, and the knowledge behind it** (232 characters)
Enter the must-finish-by date and minus five appears down the chain. Two minutes, and any trained operator does it.
Knowing the file has to be told the contract date, and where that date comes from, is a different kind of knowledge.

**Post 4/7 — same theme, bigger money** (246 characters)
Budget £4.0m. Actual cost £2.10m.
Duration field reads 60% → EV £2.40m → CPI 1.14 → EAC £3.50m.
Units installed read 45% → EV £1.80m → CPI 0.86 → EAC £4.67m.
£1.17m apart, and nobody typed a wrong number. The tool earned what it was told to earn.

**Post 5/7 — where the line sits** (257 characters)
Which field earns value is a rules-of-credit decision. It is settled before the software is opened, evidenced at measurement and defended at month end against a ledger with its own cut-off.
Product certifications for scheduling software examine the product.

**Post 6/7 — and they examine it properly** (246 characters)
Data structures, calendars, constraints, resource loading, baselines, layouts, reporting. Real material, tested seriously.
If a job advert names the package and your hands are not fast in it, do that certification first. Nothing here replaces it.

**Post 7/7 — the other subject** (269 characters)
PCL-AI examines the discipline the file expresses: 13 domains, 61 knowledge areas, a Body of Knowledge weighted 40/40/20 across finance and reporting, delivery and governed AI.
PCI is new and not accredited — read the syllabus and judge it.
