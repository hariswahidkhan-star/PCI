# Choosing a credential as a controls manager

*X / Threads. Nine posts, each able to stand alone. The link goes in the first reply, not in
post 1.*

---

**1/**
Three forecasts. One dataset. £3.7m between them, and all three defensible.

Here is the arithmetic, and the credential question a project controls manager should take from
it.

**2/**
Budget at completion £40.0m. Actual cost £18.0m. Earned value £16.4m.

CPI = 16.4 ÷ 18.0 = 0.911
SPI = 0.95

**3/**
Overrun was a one-off: 18.0 + (40.0 − 16.4) = £41.6m

Performance to date holds: 40.0 ÷ 0.911 = £43.9m

Both pressures persist: 18.0 + 23.6 ÷ (0.911 × 0.95) = £45.3m

**4/**
Nothing separates those three but an assumption a person chooses and then defends.

Choosing among them is the competence. Reciting the formulas is not.

**5/**
Where progress is measured by costs incurred against total expected costs, that forecast is the
denominator.

So £3.7m of forecast spread is also a spread in recognised revenue and reported margin.

**6/**
Present £43.9m and the question back is "what happens at £45.3m, and is it provided for".

That is not an arithmetic question, and controls method does not answer it.

**7/**
The established project controls certifications examine measurement, progress, forecasting and
the control of delivery.

Cost and scheduling credentials examine estimating, cost control, planning and schedule analysis.

Both thoroughly, by design.

**8/**
The cut-off calendar belongs to neither. PCL-AI examines that join: 13 domains, 61 knowledge
areas.

If your grading matrix names a certification, take that one instead.

**9/**
credentialfinder.org is run by Project Controls Institute Global, which awards PCL-AI.

PCI is new and not accredited — read the syllabus and judge it. It is published free, in full,
before anyone pays.
