# How to verify any credential, in about sixty seconds

*X / Threads thread — 8 posts, each under 280 characters and each able to stand alone. The link goes in the first reply, not in the thread. Character counts are for production; X counts any URL as 23 characters.*

**Post 1/8 — the hook** (202 characters)
A certificate PDF is a picture of a claim, and pictures are easy to edit. Verifying the record behind it takes about a minute, and it is the same minute whatever the credential is and whoever issued it.

**Post 2/8 — start with the ID, not the document** (234 characters)
Step one: take the credential ID and the exact designation off the document.

Step two: reach the issuing body's register yourself. Not a link the holder emailed you. If the address is not on the issuing body's own domain, stop there.

**Post 3/8 — read a state, not a yes** (231 characters)
A register worth trusting returns a state, not a yes or no. Active. Expired. Suspended. Revoked.

Expiry should be computed at the moment you ask, so a record stored as active with an expiry of 30 June comes back expired on 1 July.

**Post 4/8 — the arithmetic of a tamper check** (236 characters)
If the issuer publishes a hash of the issued file, recompute it and compare every character.

Eight hex characters is 32 bits: 16^8 = 4,294,967,296 variants, which a laptop grinds through. Sixty-four characters is 2^256. Compare all 64.

**Post 5/8 — what a register cannot tell you** (254 characters)
What a register proves is that the record is real. It does not tell you the credential fits the job.

Scope is the separate question. Cost and scheduling, financial reporting, assurance, delivery management: different categories examine different things.

**Post 6/8 — read the wording** (252 characters)
Read the wording twice. A certificate of attendance records that somebody turned up.

Honorary and member designations are not passed examinations. PCI holds honorary recognition in its own register with its own numbers, never reported as an exam pass.

**Post 7/8 — when this is not your first question** (240 characters)
If your procurement rule requires an accredited credential, settle that before you check anything else. A clean register entry for an unaccredited credential still will not satisfy the rule, and contract stage is a costly place to find out.
