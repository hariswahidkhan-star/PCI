# Two forecasts, one month, £600k apart: 7 posts

*X / Threads thread — 7 posts, each under 280 characters and each able to stand alone. No link in the thread itself; the link goes in the first reply. X counts any URL as 23 characters.*

**Post 1/7 — the hook** (168 characters)
Two estimates at completion for the same package, in the same month, £600k apart. Both defensible. The difference is one assumption nobody wrote down.

**Post 2/7 — the figures** (149 characters)
Budget at completion £10.0m. At cut-off, earned value £4.0m and actual cost £4.4m.

CPI = 4.0 ÷ 4.4 = 0.909. Forty per cent of the work is done.

**Post 3/7 — the arithmetic** (196 characters)
Assume today's performance continues: EAC = 10.0 × 4.4 ÷ 4.0 = £11.0m.
Assume the rest runs to budget: EAC = 4.4 + (10.0 − 4.0) = £10.4m.

Same data. £600k apart. The assumption decides.

**Post 4/7 — why it is a credential question** (211 characters)
Whoever defends that number in the review is arguing about method: which assumption holds, and what evidence supports it. That is a taught skill, and which credential teaches it is a question about scope.

**Post 5/7 — the categories** (247 characters)
Project management certifications examine running a project across people, process and the business environment.
Cost and scheduling credentials examine estimating, cost control, planning and schedule analysis.
Each does its own subject properly.

**Post 6/7 — how to choose** (238 characters)
Pick by the argument you lose most often, not by which name is better known.

And if an employer, a client framework or a tender mandates a certification, the mandate decides. Take that one and keep scope for the next decision.
