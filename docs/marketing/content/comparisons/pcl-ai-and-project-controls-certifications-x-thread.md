# Project controls certifications: where PCL-AI sits

*X / Threads. Seven posts, each able to stand alone. The link goes in the first reply.*

---

**1/**
Two forecasts from the same month-end data, £490k apart. Both defensible.

Here is the arithmetic, and the credential question hiding underneath it.

**2/**
Budget at completion £8.0m. Cost to date £4.0m. Earned value £3.6m.

CPI = 3.6 ÷ 4.0 = 0.90

**3/**
Remaining work at budget:
EAC = 4.0 + (8.0 − 3.6) = £8.4m

Remaining work at the achieved rate:
EAC = 8.0 ÷ 0.90 = £8.89m

Same data. £490k apart. The difference is the assumption.

**4/**
Now the part that decides which one matters.

If the package is heading for a loss, that loss reaches the accounts as soon as it is known —
and the forecast method somebody picked sets its size.

**5/**
The established project controls certifications examine measurement, progress, forecasting and
the control of delivery, thoroughly and by design.

What the number does after it leaves the control cycle sits outside their scope.

**6/**
PCL-AI examines both sides: 13 domains, 61 knowledge areas, the control cycle and the handover
into reporting.

If you want a credential from a body with a long record, that is not us. PCI is new.
