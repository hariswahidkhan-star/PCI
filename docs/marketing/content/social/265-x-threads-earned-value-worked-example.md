# EV, PV and AC: the three numbers, one worked month

*X / Threads thread — 7 posts, each under 280 characters and each able to stand alone. The link sits in the final post. Character counts are for production; X counts any URL as 23 characters, so the live figures run lower.*

**Post 1/7 — the hook** (203 characters)
PV £9.60m. EV £8.64m. AC £9.55m.

Three numbers at one cut-off. Everything else in the cost report is arithmetic on top of them, and most arguments at month end are really arguments about the middle one.

**Post 2/7 — one line each** (227 characters)
Planned value is the budget for the work the baseline said would be done by now. Earned value is the budget for the work actually done. Actual cost is what that work has cost. Budget at completion here is £24.0m, month 7 of 18.

**Post 3/7 — the arithmetic** (167 characters)
CV = EV − AC = 8.64 − 9.55 = −£0.91m.
SV = EV − PV = 8.64 − 9.60 = −£0.96m.
CPI = 8.64 ÷ 9.55 = 0.905.
SPI = 8.64 ÷ 9.60 = 0.900.
Percent complete = 8.64 ÷ 24.0 = 36%.

**Post 4/7 — the forecast, and the reality check** (212 characters)
EAC = BAC ÷ CPI = 24.0 ÷ 0.905 = £26.53m, so VAC = −£2.53m.
TCPI = (24.0 − 8.64) ÷ (24.0 − 9.55) = 1.063.
Work to date has cost £1.10 per £1 of budget. To land on £24.0m the rest must run 6.3% better than budget.

**Post 5/7 — where EV actually comes from** (222 characters)
Not from a feeling. Structural steel: 1,240 t erected of 3,500 t, control account budget £4.20m. 1,240 ÷ 3,500 = 35.4%, so EV = 0.354 × 4.20 = £1.488m. The measurement rule is written before the month, not chosen after it.

**Post 6/7 — the SPI trap** (200 characters)
As a job finishes, EV climbs to BAC and PV does the same, so SPI drifts back to 1.00 even on a project running late. It is a cost-shaped proxy for time. For time, read the critical path and the float.

**Post 7/7 — where the three numbers go next** (246 characters)
They do not stop at the cost report. Under an input method of measuring progress, cost incurred over total expected cost drives the revenue recognised.
