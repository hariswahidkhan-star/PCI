# Reading an as-built programme like a forensic planner

*X / Threads thread — 8 posts, each under 280 characters and each able to stand alone. The link sits in the final post. Character counts are for production; X counts any URL as 23 characters, so the live figures run lower.*

**Post 1/8 — the hook** (224 characters)
Planned 3 Mar to 12 Jul. Actual 17 Mar to 8 Sep.

Fifty-eight days late, and the bar chart shows one number. Fourteen of those days are a late start. Forty-four are slow running. Different causes, different owners, same bar.

**Post 2/8 — what the method is** (228 characters)
As-planned versus as-built is the simplest delay method there is: lay the baseline dates beside the actual dates, activity by activity, and measure the difference. It is observational. It shows what happened, not what caused it.

**Post 3/8 — the arithmetic** (199 characters)
Piling and substructure package.

Planned 132 days, 3 Mar to 12 Jul.
Actual 176 days, 17 Mar to 8 Sep.
Start slip = 14 days.
Duration extension = 176 − 132 = 44 days.
Finish slip = 14 + 44 = 58 days.

**Post 4/8 — what 58 days does not tell you** (222 characters)
It does not tell you which path was critical while the delay was happening. The critical path moves. A gross comparison credits the activity that looks worst at the end, not the one that was driving completion at the time.

**Post 5/8 — check the file before you analyse it** (240 characters)
Six checks on any as-built file: data date, retained logic or progress override, out-of-sequence work, calendars, constraints, and actual dates sitting after the data date. Any one of them can manufacture the delay you are about to explain.

**Post 6/8 — split it into windows** (200 characters)
Cut the job at each change of critical path. Same 58 days, now allocated:

Window 1, late access: 22 days.
Window 2, design change: 19 days.
Window 3, both parties driving: 17 days.
22 + 19 + 17 = 58.

**Post 7/8 — the 17 days are the argument** (230 characters)
Concurrency is where the analysis stops and the contract starts. Regimes differ, and entitlement to time is a separate question from entitlement to money. Show the days and the causes. Do not bury the conclusion inside the method.

**Post 8/8 — where this sits** (248 characters)
As-built comparison is where a delay analysis starts, not where it ends. The technique changes the answer, so pick it before you know which answer you want.
