# Archived: comparison pages built around named institutions

Eight pages, moved out of the publishing set on the owner's instruction that the estate carry
no risk.

Each was built entirely around a named-body search query — the slug, the title and the primary
keyword all name an external certifying body or credential. There is no converting them to
category level, because the named keyword *is* the page: strip the name and nothing is left to
target, and the ground is already covered by `best-project-controls-certification` and
`best-certification-for-planning-engineers`, which name nobody and stay in the run.

| File | Targeted |
|---|---|
| `093-…-aace-ccp-vs-pmp` | a two-credential comparison query |
| `094-…-pmi-sp-vs-aace-psp` | a two-credential comparison query |
| `095-…-pmi-sp-worth-it` | a single-credential evaluation query |
| `096-…-aace-certification-cost` | a fee query |
| `097-…-ccp-certification-worth-it` | a single-credential evaluation query |
| `098-…-ccp-exam-questions` | an exam-content query |
| `099-…-pmi-sp-exam-prep` | a study-plan query |
| `100-…-aace-psp-certification-guide` | a credential guide query |

## Why moved rather than deleted

The work is sound and the decision is a risk judgement, not a quality one. If the position
ever changes — accreditation is granted, or counsel advises the comparison route is safe —
these are here to restore. Nothing in the live run links to them, and they are outside every
build and audit path.

## What replaced them

Category-level comparisons in `../comparisons/`, which make the same argument about scope
without naming anyone, plus fifteen evaluation guides on how to judge any certifying body —
including the questions that are awkward for PCI itself.

## The blocker that forced the decision

Two writing agents independently reported the same thing: they could not link to these pages,
because the URL string itself names a credential. Eight of the ten credentialfinder.org pages
were unlinkable, which left the domain with two usable internal targets and no working link
architecture. The archive is what unblocks it.
