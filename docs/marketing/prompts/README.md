# Platform execution prompts

One prompt per platform, written as instructions to an agent that can actually operate the
account — not as marketing advice. Each follows the same arc:

> open the platform → inspect the account → decide what should go out → create it →
> quality-check it → publish it → verify it is live → capture the URL → engage → report

## The rule that makes them different from a content brief

**Do not hand back a caption when you can perform the action.** Every prompt says so
explicitly, and every prompt also says the opposite thing that keeps it honest: never claim
something was published unless you opened the published post and saw it live. A draft is not
a post. Where authentication, a CAPTCHA, a permission or a payment genuinely blocks
execution, the agent stops there and names the one action the owner has to take.

## Use the audited library first

347 pieces are already written, claim-checked and link-audited in `../content/`, indexed in
`../PCI-content-posting-pack.xlsx` and reproduced in full in `../PCI-ready-to-post.docx`.
Every prompt tells the agent to publish from that library before writing anything new,
because an audited asset has already survived a claims check, a link check and an adversarial
review. New writing is for what the library does not cover — a live industry development, a
reply that needs substance.

## The four claims that appear in every prompt

They are absolute, and they are repeated in each prompt rather than referenced, because an
agent operating one platform will not read the others.

1. 15,613 calculation checks only ever in a sentence that also says it covers PFL-AI and
   PML-AI. PCL-AI has no equivalent suite.
2. 40/40/20 describes the Body of Knowledge, never an examination weighting.
3. No accreditation, recognition, endorsement, affiliation or partnership.
4. No pass rates, student numbers, salary figures or success statistics.

## Link discipline, also in every prompt

One link per piece. Never two PCI domains in one piece of content. PCI operates five domains
and a piece that links several of them together is read as a link network — the cost is all
five losing standing at once, not one piece underperforming.

## One honest limitation

A prompt cannot give an agent access to an account its environment cannot control. These
push execution to the maximum available capability and stop cleanly where it runs out. They
do not pretend, and they must never report a post that did not happen.
