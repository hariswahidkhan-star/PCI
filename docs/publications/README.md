# PCP-AI — Public Certification Documents

Publication-ready documents for the Certified Project Controls Professional — AI (PCP-AI), for the PCI
website, candidate portal, training partners and social channels. Written from the platform's real
examination settings and the PCP-AI Body of Knowledge.

| File | Document | Use |
|---|---|---|
| `01-pcp-ai-exam-content-outline.md` | Exam Content Outline (Blueprint) | The authoritative public syllabus: 3 areas, 13 domains, 61 KAs, weightings, format |
| `02-pcp-ai-candidate-handbook.md` | Candidate Handbook | Eligibility, fees, format, booking, proctoring, results, recertification, conduct, appeals |
| `03-pcp-ai-certification-overview.md` | Certification Overview | Prospectus / "why this credential" — website hero, one-pager, LinkedIn |
| `04-pcp-ai-sample-questions.md` | Sample Questions | Twelve public study items with answers and rationale |

`PCP-AI-Candidate-Information-Pack.pdf` compiles documents 01–04 into one downloadable pack.

**Notes for publishing.** Fees, dates, CPD hours and the final examination specification are the
Institute's current settings — confirm them on the official site before publishing. Sample questions are
study items kept separate from the live examination bank. British English throughout.
